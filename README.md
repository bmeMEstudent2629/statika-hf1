# Statika HF1 kalkulátor

A BME GPK Statika 1. házi feladatához készült kalkulátor: térbeli erőrendszer redukálása az origóba, az M_f nyomaték és a centrális egyenes origóhoz legközelebbi G pontja.

Megnyitás után add meg a saját lapod „Adatok” táblázatának összes értékét. Az oldal kiírja a Moodle-be beírandó értékeket (F, M_O, r_G), a teljes részeredmény-táblázatot és a lépésenkénti levezetést a megadott számokkal. Egy méretarányos axonometrikus vázlatot is rajzol.

Az oldal egyetlen statikus `index.html` fájl, a képleteket a KaTeX (jsDelivr CDN) jeleníti meg.

## Az ábra értelmezése

- B = (a; 0; 0), C = (a; b; 0), D = (0; b; 0), A = (a; 0; c), E = (0; b; c)
- F₁ a B, F₂ az E, F₃ a C pontban hat; mindhárom erő három koordinátával adható meg (az alap lapon F₂ +y, F₃ +z irányú)
- M₂ = (0; 0; −M₂), M₁ szabad vektor
